# 稳定性承诺（冻结声明）

> **一句话**：从 `0.23.0` 起，这个库进入**只增不减**的冻结期。
> 公开名字（令牌、类名、JS 成员、CLI 子命令、契约字段、文件路径）
> 不消失、不改名、不改语义；渲染细节、注释、文档、门禁随时可改。
> 冻结**不是**"停止维护"，是"改动必须对下游可见"。

---

## 1 · 为什么写这份文件

"别动了"这句话有两种翻译，而它们的后果完全相反：

| 翻译 | 后果 |
|---|---|
| 不再发布、不再修 | 下游遇到 bug 只能自己打补丁，一年后没人敢升级 |
| 不再**破坏** | 下游可以放心把版本号写死，而修复继续到货 |

这份文件选第二种。它把"冻结"定义成一组**可被机器检查**的承诺，
每条承诺都指着一个正在跑的门禁 —— 没有判据的承诺不写在这里。

---

## 2 · 冻的是什么（承诺 ↔ 判据）

| 承诺 | 具体到 | 谁在守 |
|---|---|---|
| 令牌名不消失 | `--text-primary`、`--sp-2` 这类名字 | `deprecation-gate.py` ⑦（`ai/surface.baseline.json` 只增不减） |
| 类名不消失 | `.btn`、`.field`、`.shell__link` 这类名字 | 同上 |
| JS 成员不消失 | `Select.open()`、`AccordionOptions.duration` 这类名字 | `deprecation-gate.py` ⑦ + `api-contract-gate.py`（d.ts ↔ 运行时**实测**比对） |
| 声明的名字真的存在 | 不许出现"文档里有、代码里没有"的幻觉 API | `gen-ai-contract.py --check`、`dead-class-gate.py` |
| 行为事件名不消失 | `fl:select` 这类事件名 | 只记在基线里，**没有运行时探针**（见 §6） |
| CLI 子命令与 `--json` 形状 | `agentcss ai <cmd> --json` 的 11 个子命令、失败也是 JSON | `ai-layer-gate.js` ⑥′⑥″ |
| 契约文件字段 | `ai/components.json` / `pitfalls*.json` / `behaviors.json` | `gen-ai-contract --check`、`ai-layer-gate` ⑦ |
| 文件路径 | `02-primitives/button/button.css` 这类 `<link>` 直接指向的路径 | `dist-parity-check`、`pack-smoke.sh`、`assets-catalog-gate.py` |
| 体积承诺 | 全库生效 CSS ≤ 172 KB，常规增长不涨价 | `perf-gate.py` + `budget-selftest.py`（见 [BUDGET.md](BUDGET.md)） |

逐条清单与总数**不写在这份文件里** —— 那是 `ai/surface.baseline.json` 的职责
（`deprecation-gate.py` 每次运行都会打印总数与「无未登记的移除」）。写在文档里的
计数一定会漂 —— 这份文件的第一版就写死过「337 个类名」，后来基线涨到 379，
没有任何门禁会因为那句话过时而变红。**数字只有一个来源，才不会有第二个版本。**

⚠️ "不消失"包含**不改语义**。把 `.btn` 从 44px 高改成 36px 不会让门禁变红，
但它一样是破坏性变更 —— 判据守不住的部分，靠这一行字约束。

---

## 3 · 没冻的（随时可以改，不需要任何流程）

| 面 | 为什么可以随便改 |
|---|---|
| CSS 选择器的**写法** | 只要渲染结果等价。合并规则、换 `:is()`、调顺序都行 |
| 注释 | 本库注释是给人读的取舍记录，跟着代码一起演进 |
| demo 页 | 它们是文档，不是 API |
| 文档、guide、README | 同上。数字由 `doc-facts-gate.py` 对账 |
| 门禁脚本本身 | 门禁只约束产品，不约束自己 —— 但它自己要被 `selftest-all.py` 约束 |
| 新增组件、新增令牌、新增类名 | 纯增量，不破坏任何下游 |
| 内部实现（JS 私有函数、`data-*` 内部状态） | 没有承诺过，也从未写进 d.ts |

⚠️ 有一条**反直觉**的：`data-state` 这类属性值是**公开的**
（`.btn[data-state="loading"]` 是文档里教人写的选择器），
所以它们属于 §2 而不是 §3，即使它们长得像内部实现。

## 4 · 版本语义（0.x 期间）

| 变更类型 | 版本位 | 例子 |
|---|---|---|
| 修复（渲染错、对比度不达标、门禁误报） | patch | `0.23.0 → 0.23.1` |
| 新增（组件、令牌、CLI 子命令、文档） | minor | `0.23.0 → 0.24.0` |
| 删除 / 改名 / 改语义 | **必须走废弃流程** | 见 `docs/DEPRECATIONS.md` |

废弃流程的硬要求（`deprecation-gate.py` ③）：**迁移窗口 ≥ 一个次版本**。
也就是说，`0.24.0` 宣布废弃，最早 `0.26.0` 才能真的删 ——
中间那个版本是给下游的。

1.0 之后这条不变，只是"次版本"变成"主版本"。

---

## 5 · 什么情况下解冻

解冻指"允许一次破坏性变更"。三个条件**全部**满足才成立：

1. **有下游证据**：至少一个真实使用方（含本库自己的 `guide/` 与 demo）
   明确表示旧名字挡路，且无法通过新增绕开；
2. **有迁移路径**：新名字先发布、旧名字标 deprecated、`replacement` 字段非空
   （`deprecation-gate.py` ⑥ 会验证替代品真的存在）；
3. **有账**：写进 `docs/DEPRECATIONS.md`，并让 `deprecation-gate.py` 的
   `retroactive` 计数**不增加** —— 那条是棘轮，只许降。

不满足就只有一个选项：**新增，不动旧的**。
本库已经这样做过多次（`metric` 与 `delta` 并存、`page.css` 里 `.cmp` 家族
替代 22 份页内副本），代价是多几十行 CSS，收益是没人被迫改代码。

## 6 · 诚实边界：这份承诺覆盖不到的地方

写出来，是因为"不说清就等于假绿"：

- **事件名**（`fl:select` 等 6 个）只在基线里，**没有运行时探针**。
  删了它，`deprecation-gate` 会红，但没有东西能证明它还会触发。
- **`data-*` 属性值**（`data-state="loading"`、`data-shell-nav`）不在
  `surface.baseline.json` 的自动采集里 —— 它们在 §2 表里是**人写的承诺**，
  不是机器守的。
- **视觉像素**。`10-review/shots/` 的 61 张基线只防"我们自己拍到的这些页面"，
  下游自己组装的页面会怎么变，量不到。
- **CSS 变量在 `@media` 里的重定义**（如强制色分支）。选择器结构和
  `forced-colors-check.js` 覆盖了 7 类缺陷，但"用户自己的强制色主题"没有。

## 7 · 怎么确认冻结没被破坏

```bash
python3 05-audit/deprecation-gate.py     # 公开名字有没有无流程消失
python3 05-audit/api-contract-gate.py    # d.ts 与运行时是否仍然一致
node    05-audit/ai-layer-gate.js        # CLI 与契约文件是否仍可用
python3 05-audit/perf-gate.py            # 体积有没有越线
```

四道全绿 ⇒ §2 的每一条都还成立。任何一道红，说明"冻结"已经被破坏，
而破坏它的那次提交就在 `git log` 里 —— 这就是这份文件想要的效果：
**让"我们改了什么"从记忆问题变成一个查询问题。**
