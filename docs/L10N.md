# 本地化（L10N）文案覆盖

> **一句话**：库默认输出中文；把 `labels` 传进去就能换掉**用户看得见、读屏会念到**的文案。
> 不传时输出与 0.25.x **逐字相同** —— 升级不会静默改变界面文字。

```html
<script src="03-patterns/pagination/pagination.js"></script>
<script>
  Pagination.create(document.querySelector('[data-pagination]'), {
    labels: { prev: 'Previous', next: 'Next',
              page: function (p, cur) { return 'Page ' + p + (cur ? ' (current)' : ''); } }
  });
</script>
```

值可以是字符串，也可以是函数（动态量用函数，例如页码、百分比）。

---

## 一、哪些文案**在**覆盖范围内

| 组件 | 入口 | 键 |
|---|---|---|
| `overlay` | `Overlay.toast({ labels })` | `closeToast` |
| `drawer` | `Drawer.open({ labels })` | `dialog`（无标题时的名字）、`close` |
| `pagination` | `Pagination.create(node, { labels })` | `nav`、`prev`、`next`、`page(p, isCurrent)`、`status(page, pages)`、`live(page, pages)` |
| `upload` | `new Upload(root, { labels })` | `pending`、`done`、`error`、`remove(name)`、`uploading(pct)`、`countMax(n)`、`sizeMax(limit)`、`type`、`folder`、`none(reason)`、`noDrop`、`noDropShort`、`summary(added,total,rejected)`、`removed(name,rest)` |
| `select` | `Select.create(root, { labels })` | `option`、`placeholder` |
| `combobox` | `Combobox.create(root, { labels })` | `suggest`、`input`、`noMatch(query)`、`empty` |
| `date-range` | `DateRange.create(root, { labels })` | `requiredEnd`、`requiredStart`、`order(from,to)`、`min(min)`、`max(max)` |
| `dropdown` | `Dropdown.create(root, { labels })` | `menu` |
| `tree` | `Tree.create(root, { labels })` | `tree` |
| `nav` | `Nav.attach(root, { labels })` | `open`、`close` |
| `tooltip` | `Tooltip.setLabels({ region })` | `region` |
| `model-viewer` | `ModelViewer.setLabels({ … })` | `load`、`placeholder`、`retry`、`preparing`、`preparingEngine`、`hintBefore`、`hintBetween`、`hintStrong`、`hintTail`、`downloading(pct)`、`noWebGL` |
| `bar` | `Bar.draw({ text })` ⚠️ | `series(i)`、`clipped(n, isStack, max)` |

`label` / `ariaLabel` 这类**单值**参数仍然有效，且优先于 `labels` ——
它们是既有 API，不为统一而破坏兼容。

### ⚠️ `bar` 为什么叫 `text` 而不是 `labels`

`bar.draw` 的 `labels` **早就是「X 轴标签」这个数据参数**（`labels: string[]`）。
把同一个名字改成文案对象是破坏性变更，所以这里的文案覆盖用 `text`。
全库只此一处例外，`types/index.d.ts` 里 `BarText` 有同样的注释。

### 没有逐实例入口的组件

`tooltip` 与 `model-viewer` 由属性自动初始化（`data-tooltip` / `data-mv`），
没有"传 opts 的地方"，所以用**模块级**的 `setLabels()`。
设置一次影响该页面上后续创建的所有实例；已经创建的不受影响。

## 二、哪些**不在**覆盖范围内（不假装已做完）

1. **开发期错误信息**：`throw new Error('upload: 缺少 .upload__input …')`。
   它们面向调用方（写代码的人），不经过 UI，也不该由终端用户看到。
   要统一英文请改源码 —— 这不属于 L10N。
2. **`model-viewer` 的失败说明与底部说明句**：
   `fail()` 的几条错误文案、`mv__cap` 里的「引擎就绪耗时 … ms」。
   它们含 `<b>` 结构与多个动态量，要安全本地化得先改成节点拼装，
   属独立改造，**当前仍是中文**。
3. **`echarts-adapter` 的控制台提示**：`[frontend-lib] 系列数 …`，
   属开发者提示，同上。

这份清单由 `05-audit/i18n-labels-gate.js` 守着：库代码里再出现
「中文字面量直接进 `aria-label` / `textContent` / `el()` 文本位」就红，
要新增必须先回答"用户会看到吗"。

---

## 三、为什么默认不改英文

- **不制造惊喜**：升级补丁版本就换掉界面语言，是比"没本地化"更糟的破坏。
- **不猜语言环境**：`navigator.language` 在 SSR、WebView、隐私模式下都不可靠，
  自动切换会让同一份代码在不同机器上显示不同语言，问题极难复现。
- **真要做多语言**，正确做法是调用方在启动时按自己的语言包调 `setLabels` /
  传 `labels` —— 词汇表由产品决定，不由组件库猜。

---

## 四、门禁

| 门禁 | 判什么 |
|---|---|
| `i18n-labels` | 静态：库代码 0 处硬编码用户文案（注释与 `throw` 不在视野） |
| `i18n-labels`（运行时） | 真浏览器里传 `labels` ⇒ DOM 真的变了；不传 ⇒ 仍是各组件的中文默认值 |
| `i18n-labels-rev` | 判据自检：三种写法都要抓到；变量/注释/`throw` 不误报；元反向 |

运行时那半条**必须先看默认值**：只断言"覆盖后等于测试串"是不够的 ——
如果把测试串直接写进源码，那条断言照样绿。
