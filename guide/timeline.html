timeline · 时间轴

时间轴：按时间排的事件序列（公告 / 大事记 / 版本记录）。顺序即信息，用 ol；状态交给 badge，颜色在这里会失效

  • 02-primitives/timeline/demo.html
  • 02-primitives/timeline/timeline.css

一串按时间排的事件：一个时点、一句标题、可选一段正文。公告列表、大事记、版本记录都是它 —— 共同点不是"有日期"，而是顺序本身就是信息。

<link rel="stylesheet" href="02-primitives/timeline/timeline.css">

<ol class="timeline">
  <li class="timeline__item timeline__item--latest">
    <time class="timeline__time num" datetime="2026-10-29">2026-10-29</time>
    <h3 class="timeline__title">2026 年三季报披露</h3>
    <p class="timeline__body">营业总收入 1,294.06 亿元，同比 +12.40%。</p>
  </li>
  <li class="timeline__item">
    <time class="timeline__time num" datetime="2026-08-27">2026-08-27</time>
    <h3 class="timeline__title">2026 年半年报披露</h3>
  </li>
</ol>

类#

类作用
.timeline根。<ol>（顺序即信息），用 <ul> 或 <div> 也能渲染
.timeline__item一条事件。position: relative + 左侧留出 --sp-5 的槽
.timeline__time时点。默认块级、tertiary 色、--fs-xs
.timeline__title标题。margin: 0，不受浏览器默认标题边距影响
.timeline__body正文，可选
.timeline__item--latest最新一条：圆点 8 → 12px、标题 600
.timeline--compact紧凑档：条目间距 --sp-4 → --sp-2，时间回到标题同一行

三条硬规矩#

  1. 用 <ol>，不是 <div>。读屏会念「第 2 项，共 4 项」； <div> 堆出来的时间轴在无障碍树里只是一串没有关系的段落。时间用 <time datetime="…">：屏幕显示"10-29"，机器仍拿到完整日期。
  2. 状态不在这里表达。要区分「已披露 / 待披露 / 停牌」，用 badge 配文字。本组件故意不给状态配色 —— 绿色和灰色在强制色模式、色盲、打印三种情况下会同时失效，而状态文字不会。
  3. "最新一条"靠尺寸和字重，不靠颜色。timeline__item--latest 只改两件非颜色的事：圆点直径与标题字重。颜色在强制色里会被替换掉，只靠"最新那条是蓝的"等于没标。

反例#

  • 拿字符画圆点 content: "●" 视觉上看不出区别，但那是一个文字：它会进 textContent、能被选中复制、也会被算进链接名（读屏念「圆点 季报披露」）。用 content: "" + 盒子画。
  • 最后一条也画连接线 列表下方会多出一截悬空的线，看起来像「还有一个事件没加载出来」。收尾靠选择器（:not(:last-child)），不靠给最后一条设透明边框 —— 透明边框在强制色里会显形。
  • 连接线用 inset-block: 0 第一条的线会从条目顶端开始，在圆点上方留一小截 —— 同样像"上面还有内容"。线应该从自己的圆心画到下一个的圆心。
  • 圆点对齐整块的中心 正文一长，圆点就往下滑，同屏几条圆点高低不齐。要对齐的是首行行盒的中心。
  • 只给一条事件也套时间轴 那不是时间轴，是一段话。连接线和圆点只会让人以为还有下文。

为什么它值得是一个组件#

四个必须一起做对的量，交给调用方"记得做"必然漏：

量错了会怎样
圆心 / 连接线中心 / 首行中心 三心合一差 1–2px，说不清哪里不对，但一眼就是歪的
连接线只画到下一个圆心首尾各多一小截，像"内容没加载完"
最后一条不留底距、不画线列表下方凭空多一块空白
圆点不用 border 画本库 box-sizing 是选配（挂在 .page * 上）⇒ 有它时圆点缩水一半

前三条由 timeline-check.js 的 B 组守着（含反向控制），第四条是 --tl-dot 只作用于宽高。

什么时候不该用它#

  • 要表达"进行到第几步"：那是步骤条，有"当前"和"未到"的语义；本组件只表示"发生过"。
  • 事件之间有嵌套/分支：时间轴是线性的。要分支用树，要并行用表格。
  • 只是"更新时间"一行字：不需要圆点和连接线，一行 small 就够。
