delta · 变化量

变化量：涨跌方向 + 符号 + 颜色。只描述往哪边变，不判断好坏（等于好恶是 badge 的事，会计正负是 table 的事）

  • 02-primitives/delta/demo.html
  • 02-primitives/delta/delta.css

一个数相对某个基准变了多少、往哪边变。不判断好坏。

<link rel="stylesheet" href="02-primitives/delta/delta.css">

<span class="delta delta--up">3.21%</span>    <!-- 渲染 +3.21%，红 -->
<span class="delta delta--down">1.05%</span>  <!-- 渲染 −1.05%，绿 -->
<span class="delta delta--flat">0.00%</span>  <!-- 无符号，中性色 -->

类#

类作用
.delta基础：等宽字族（--mono）+ 不换行
.delta--up涨：默认红（口径见下）
.delta--down跌：默认绿
.delta--flat持平：中性色，不带符号
.delta--arrow把符号换成 ▲ / ▼（与符号档互斥）
.delta--sm紧凑档，用于表格行内

三条硬规矩#

  1. HTML 里只写数值本体，不写 + / −。符号由 CSS 生成，手写就是两个符号。
  2. 方向由你给，组件不推断。本组件没有 JS、不读数值 —— 类名写错就颜色错，且不报错。
  3. 值为 0 用 --flat，塞进 --up / --down 等于伪造方向。

反例#

  • ❌ HTML 里手写符号 —— 数据侧照着习惯写 −1.05%，组件再补一个减号，渲染成 −−1.05%；页面不崩、控制台不响，只是报表看起来像坏了。demo 里有两栏真实对照（字形 7 对 6），05-audit/demo-claim-gate 逐栏量
  • ❌ 拿它表达好坏 —— delta--up 说的是方向，不是评价。「研发费用 +38%」确实是涨，但那是成本失控；要表达成功/失败/警告用 badge 的语义档
  • ❌ 把涨跌幅塞进表格的 num--pos —— 那是会计约定（正 = 绿），套在涨跌幅上正好与 A 股习惯相反。表格里的涨跌幅列用 delta，不要用 num--pos
  • ❌ 方向靠猜 —— 本组件不读数值、也不推断正负。类名写错就颜色错，而且不报错；值为 0 必须用 delta--flat，塞进 --up 等于伪造方向
  • ❌ delta--arrow 与符号档同时加 —— 两者抢同一个 ::before。同时加不会双显，但说明你以为它们能叠加，按这个理解去写别的组合就会踩空

口径：红涨绿跌是缺省，不是唯一#

默认 A 股口径。给任意祖先加 data-market="intl" 切成国际口径（绿涨红跌）：

<html data-market="intl">
<!-- 或只切一块 -->
<section data-market="intl"> … </section>

实现方式与暗色同构：--dir-up 永远表示“涨”，口径切换只改令牌的指向，组件 CSS 里没有任何 [data-market] 分支。两栏 HTML 逐字相同，只差那个属性。

与另外两组颜色的分工#

想表达用什么语义
状态（已停牌 / 审计中）badge 的 badge--success 等一个词，没有数值
会计正负（营收 -3.2 亿）table 的 num--pos / num--neg正 = 绿，负 = 红（红字）
变化方向（同比 +12.4%）delta 的 delta--up / --down只描述往哪边变

三者不可互换 —— 用错不会报错，只会让报表在某个具体场景里说出相反的结论。

读屏拿到的是什么#

+ / − 由 CSS 生成，所以它们不在元素的 textContent 里。但实测（Chromium + CDP 可访问性树）：它们是独立的 StaticText 节点，读屏会按顺序念「加」「3.21%」。也就是说方向对读屏用户是可用的，不是只靠颜色。

⚠️ 这个机制很容易被改坏：把 content 换成空串、换成背景图、或让伪元素 visibility: hidden，视觉上可能仍有符号，可访问性树里就没了。 05-audit/delta-check.js 的判据 ⑦ 直接数十字树里的 + / − 节点（破坏实验证明它会红）。

实测对比度#

05-audit/contrast.py，四组底（纸底 / 表面 / 内凹 / 卡片）各算一遍：

令牌浅色暗色
--dir-up（红）4.89 – 5.445.60 – 6.15
--dir-down（绿）5.75 – 5.966.01 – 6.60

全部 ≥ 4.5（AA）。最差的一格是红点在 --surface-sunken 上 4.89，12px 字号下仍达标。

为什么强制高对比模式不用额外处理#

+ / − 与配色无关，强制色抹掉红绿之后符号仍在表达方向 —— 1.4.1 要的 “信息不能只由颜色承载”本来就成立。这里故意没写 @media (forced-colors: active) 块。
