组件文档

37 个组件，按「基础件 → 模式 → 版式模板 → 图表」排列。 每一项都能点开示例，样式与行为脚本可以整段复制走。

组件之间没有 CSS 依赖：任意一个组件的样式表只用到 01-tokens 的令牌，不会 @import 别的组件。 只要 tokens.css + 这一个文件；行为脚本按需再加。

全局约定（不属于任何组件）

令牌用法、焦点环、动效时长、暗色切换、逻辑属性 —— 这些规则跨全部组件，改一处影响全站。

  • 全局约定令牌三层、间距台阶、焦点环、动效时长、暗色三态、逻辑属性、能不能用 @layer 与 !important
  • 无障碍目标等级、验过的范围与手段、已知缺口、自测命令
  • 弃用与移除删除公开名字必须先登记、迁移窗口有多长、现在有哪些名字在案、以及我们管不住哪些名字
