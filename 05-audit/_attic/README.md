# _attic —— 退役脚本

> **这里的东西不再运行。** 留着的唯一理由是：它们记录了当时怎么想问题。
> 想复活任何一个：先回答"它解决的那个问题现在还在吗"，再把它**接进 `check-all.sh`**
> 或**移到 `05-audit/` 根目录并让 `orphan-gate` 认得出调用方**——不要只是搬回去。

| 脚本 | 为什么退役 |
|---|---|
| `cache-gate.js` | 自称"门禁自己的门禁：证明测试环境没有缓存"。实测它一条引用都没有，缓存问题后由 `browser.js` 统一处理（每个 `newPage` 用独立 context）。 |
| `flicker-scan.js` | 早期扫"页面加载闪烁"。动效的现代判据已经换成 `motion-concurrency.js`（真浏览器量动画对象），静态扫文本的做法不再有信息量。 |
| `ios-safe.js` | 窄屏安全性检查。真机基线至今未做（ROADMAP W10），这个脚本只覆盖了模拟宽度，结论会给人"已经验过 iOS"的错觉——**有比没有更糟**，因此下线。 |
| `mkindex.py` | 生成演示站入口页。`index.html` 已经手写成稳定版，生成器的输出与它逐字相同后即失去意义。 |
| `scan-control-markup.py` | 扫可点控件的 HTML 写法。该职责已由 `contract-kit.js` 的命中区判据（每个组件契约都跑）覆盖，且后者在真浏览器里量的是实际矩形。 |

## 为什么不直接删

删掉之后，半年内一定会有人重新写一个几乎一样的脚本（`ERRORS.md` E31：
"同一个判定逻辑写两份 ⇒ 两道门禁互相打架"）。留一份带理由的墓碑，成本是几十 KB，
换来的是"这件事我们想过、当时为什么放下"可查。

## 与 `orphan-gate` 的关系

`orphan-gate.py` 会**跳过 `_attic/`**。所以把脚本移进来就等于声明"它退役了"，
不需要再去门禁里登记一条豁免。
