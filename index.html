agentcss · 演示

35 个组件，每一页都能直接打开看。 手机上也一样 —— 布局、触控尺寸、暗色都是按移动端调的。

基础组件

单一控件。拷一段 CSS 就能用。

  • badge · 状态标记状态标签：计数、分类、结果标记
  • button动作触发：主/次/危险/纯文字四档
  • card内容容器：媒体+正文+操作区三段
  • checkbox / radio / select单选/多选/原生 select 外观的统一控件
  • combobox · 组合框 / 标签输入可搜索 + 可多选标签的输入控件
  • date-range · 日期区间日期区间选择，含预设快捷范围
  • input / field文本输入及其标签/帮助/错误三件套
  • popover · 气泡卡片锚定到触发元素的浮层
  • progress · 进度条进度条与进度环
  • select · 自建下拉选择自定义下拉选择（非原生）
  • separator · 分隔线分隔线，可带中间文字
  • skeleton · 骨架屏加载占位骨架
  • switch · 开关开关切换

模式

由多个控件组成的一种交互，通常带行为脚本。

  • accordion · 折叠面板可折叠分组
  • content —— 内容渲染样式长文排版容器（标题/段落/列表/引用/代码）
  • drawer · 抽屉侧边抽屉，含遮罩
  • dropdown · 下拉菜单下拉菜单
  • 表单校验表单校验反馈与错误汇总
  • list —— 列表键值列表/条目列表
  • nav —— 页头 / 目录 / 移动端抽屉顶部导航与目录
  • Toast / Dialog（反馈层）吐司提示与模态遮罩
  • pagination · 分页分页控件
  • reveal · 入场动效入场动效：一个 data-reveal 属性六个方向，无 JS 时内容全可见
  • 容器四态：empty / loading / error / success空/加载/错误/成功四种整块状态
  • tabs · 标签页选项卡切换
  • tooltip · 文字提示悬停/聚焦提示
  • tree · 树形视图可展开树形结构

版式模板

一整页的排版约定，给"有结论、有数据"的材料用。

  • analysis-report · 组合型研究报告组合型研究报告页面：正文与辅助栏并排，窄屏自然退回单栏
  • detail-page · 实体详情页骨架实体详情页骨架：字段齐全 / 部分缺失 / 无数据三种状态同构，无数据是一等状态
  • report · 报告版式系统 v1报告版式系统 v1：共享基础 + 三套版式（杂志/科研技术/金融研究），只换一个 rep--* 类即可切换取舍
  • table · 专业数据表格数据表格：排序/加载/空/错误四态；三种用途预设（财务/学术/统计）

图表与资源

数据可视化与可选的第三方适配层。

  • bar · 柱状图柱状图：堆叠/分组两种语义、超量程裁剪、图例
  • model-viewer — 惰性加载的 3D 模型查看器3D 模型查看器：令牌驱动样式，不含渲染库本体
  • scientific-plot · 二维科学绘图二维科学绘图：折线/区间带/对数轴，纯令牌驱动、零依赖
  • sparkline · 迷你趋势图迷你趋势图：无坐标轴、纯形状，适合表格内嵌的一行走势
