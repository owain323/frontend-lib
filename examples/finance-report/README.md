# 金融分析示例页

一张完整的 A 股公司分析页，用来回答一个问题：**把本库的组件拼成真实产品的一页，
站得住吗？**

单个组件的 demo 证明不了这件事 —— 每个组件都对、拼起来错位，正是组件库最典型的
失败方式（列宽互不相让、字号层级打架、图表被容器压扁）。这一页是那件事的反例。

## 怎么看

在仓库根目录起一个静态服务器（`python -m http.server` 就行，不需要构建）：

```
http://localhost:8000/examples/finance-report/
```

建议按这个顺序看，每一处都对应一个具体判断：

| 看什么 | 它想说明的 |
|---|---|
| 窄屏（375 / 393）| 单栏是**重排**出来的，不是把桌面版缩小 |
| 宽屏（≥ 992）| 正文 700 + 边注 224 + 间距 36 = 960，三个数是算过的，不是试出来的 |
| 点右上角主题 | 明暗两套都成立，没有任何一个写死的颜色 |
| 切三个报表 tab | 三张表结构不同，共用切换器但不共用列 |
| 看「五年主要指标」 | 单位在列头、缺失写「—」不写 0、列头与数字同侧对齐 |
| 读「风险与不确定性」 | 一份没有风险披露的研究报告是不完整的作品 |
| 手机上点汉堡 | 抽屉 + 遮罩 + Esc 关闭 + 焦点归还 |

## 数据

**全部数值是演示用示例数据** —— 但"示例"不等于"随便编"。

这一页的 30 条勾稽全部成立，而且**能被读者自己用页面上的其他数验算出来**：

- 利润表：收入 − 六项成本费用 + 其他项目净额 = 营业利润 = 1,402.8；
  再减所得税 = 净利润 − 少数股东损益 = 归母净利润 998.3
- 资产负债表：负债 451.6 + 归母权益 3,000.3 + 少数股东权益 300.0 = 资产总计 3,751.9
- ROE 34.6% = 归母净利 ÷ 平均归母权益（期初 = 期末 − 本年增量）
- 五年表的归母净利率、研发费用，逐年与收入勾得上；图 1 的分部、图 2 的费用率
  与表 1 是同一组数
- 侧栏估值四数：18,968 ÷ 998.3 = 19.0（PE）；18,968 ÷ 3,000.3 = 6.3（PB）；
  998.3 × 75% ÷ 18,968 = 3.9%（股息率）

这不是靠自觉维持的：`05-audit/finance-example-ties.py` 每次门禁都把这些数
重新加一遍，**改一个数忘了改另一处就会红**。它自己也被 8 个变异探针验过。

页面里每一处用到数字的地方都标注了数据性质 —— 示例页最不该做的事，
是让人把示例数字当结论。

## 它同时暴露过五个缺陷（四个在库、一个在我）

这一页不是"先有组件、后凑个页面"，是**先按真实产品的要求写，撞到墙再回头修库**：

1. 导航在系统开启「减少动态效果」时整个飞出屏幕（`nav.css`）
2. 财务表的列头与数字不同侧，列头居中、数字靠右（`table.css`）
3. 柱状图的 `viewBox` 宽度写死 640，窄容器里刻度字缩到 3×6 像素（`bar.js`）
4. tab 栏没有任何溢出处理，320 屏把整页撑出横向滚动条（`tabs.css`）

四条都已修，`CHANGELOG.md` 里逐条写了实测数据。
其中第 1 条**只在 reduced-motion 下出现**，默认环境的截图永远拍不到它 ——
这一页因此被纳入视觉基线，成为回归的一部分。

第 5 个是我自己的：第一版交付时这三张表**加不上**（利润表差 79.4 亿、
资产负债表少一行、五年表研发费用差 6 倍），而所有门禁都是绿的。
台账记在 `ERRORS.md` E60，判据补成了 `finance-example-ties.py`。

## 自己改的时候

- 页面级样式全在 `page.css`，**只写库没有的排布**，颜色间距字号一律走令牌。
  它开头的注释说明了为什么宽度是改令牌而不是改规则。
- `index.html` 里的脚本是 ES5（本库硬约束：老 WebView 上 `const` 直接语法错误）。
- 图表宽度必须**量容器**再传（`host.clientWidth`），不要写死设计宽度 ——
  原因见 `bar.js` 里 `var W = ...` 上方的注释。
