3D 模型查看器

惰性加载：首屏 0 字节 3D 引擎，点了才下载。 这是 确定的三条硬要求之一（「体积和加载一定要快」）。

试试看：小狐狸

先别急着点按钮 —— 打开开发者工具的 Network 面板， 首屏不会有 three.js。点下去才出现 three.min.js GLTFLoader.js OrbitControls.js。

为什么是这样设计的

要求做法
首屏要快 3D 引擎点击后才 <script> 注入， 首屏 0 KB；模型走 XHR 以便显示真实进度
绝不能白屏 WebGL 不支持 / 库没来 / 模型 404 / 解析失败 —— 四种失败全部给中文提示 + 重试按钮
视觉统一 颜色、圆角、间距全部走 var(--*)，换主题跟着变
iOS 手感 touch-action: none 让拖动不触发页面滚动； 关掉 tap highlight；页面切后台停止渲染省电

边界（本库不做什么）

  • 不把 three.js 打包成本库的依赖 —— 592KB 违背「零依赖」；而且素材里那两个 loader 是 ES6， 与「JS 一律 ES5」冲突（精简档 的 WebView 会直接语法错误）。
  • 精简档（某项目）不做 3D —— WebGL 在老 WebView 上大概率不可用。 本组件会检测并给出明确提示，不会白屏。
  • 不自己手搓 glTF 解析器 —— 用成熟的 GLTFLoader。
