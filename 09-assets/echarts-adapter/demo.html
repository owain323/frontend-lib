图表规范

下次画图照这里做就行，不用再反复微调。 全部规则来自本库的分析类可视化约定， 并且大部分已经变成 echarts-adapter.js 里的默认值 —— 你不写，它就帮你合规。

0 · 边界：什么该用本库，什么该用 ECharts

场景用什么谁维护
列表右侧的迷你趋势（看走势） 本库 sparkline（1.5KB，零依赖）我们
表格里的迷你条 / 状态点本库我们
多系列折线 / 柱 / 饼 / 桑基 / 热力 / 仪表盘 ECharts 或 Recharts他们

判据一句话：「看走势」用本库；「看数据、用它做判断」用 ECharts。

⚠️ 精简档（某项目）不要引 ECharts（约 1MB gzip）——那边继续用 sparkline。

1 · 本库负责的：迷你趋势（sparkline）

600519 1,684.20 +2.31%
000001 11.87 −0.84%

🔴 旁边必须有数字——sparkline 本身没有可读的信息 （读屏读不出路径）。这是它最容易出的错。

3 · 数字格式（已经在用）

类型规则例子
千分位每三位加逗号1,234,567
百分比固定 1–2 位小数42.6%
大额走「万 / 亿」，不写成 100,000,0001.28 亿
缺失值留空，不写 0—

🔴 缺失 ≠ 0：这是本库的 MISSING != ZERO 契约，图表里同样适用 —— 缺失点应该断开，不能画成 0。

4 · 明确禁止（这些是"看起来专业但会骗人"的）

不要做为什么
3D 图表透视扭曲会误导读数（Tufte 的核心结论）
双 Y 轴两轴的交叉点可以被随意搬动 ⇒ 视觉在说谎
大面积渐变填充只在面积图用，透明度 ≤ 0.15
只用颜色区分系列色盲用户看不出 ⇒ 加虚线或标记点
平滑曲线（smooth）会造出数据里没有的中间值，adapter 已默认关掉

5 · 无障碍

  • 图表旁必须有等价的数字或表格（本页每个图都配了表）
  • 数据图表的 <svg> 加 role="img" + aria-label
  • ⚠️ 装饰性 sparkline 反而不要 加 role="img" ——它没有可读等价物，加了会误导
  • 不能只用颜色区分系列

6 · 怎么用（下次直接照抄）

<script src="echarts.min.js"></script>              <!-- 主项目引 -->
<script src="09-assets/echarts-adapter/echarts-adapter.js"></script>

var c = ChartAdapter.create(document.getElementById('chart'), {
  xAxis: { type: 'category', data: ['Q1','Q2','Q3','Q4'] },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', data: [128.4, 136.1, 141.7, 155.2] }]
});
// ↑ 就这样。主题、y 轴从 0、字号、网格边距都已经合规了。

换主题时调 ChartAdapter.refresh(c)，图表会跟着变 （配合 01-tokens/theme-toggle.js）。
